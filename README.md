          

PROJECT TITLE: Ecommerce Dataset


PROJECT OVERVIEW

                 An e-commerce dataset contains information about sales, customers, products, orders, revenue, and payments.It helps businesses understand customer behavior, identify best-selling products, and track sales performance. It also helps to find insights around the country with loyalty level.
                 
The main objective was to prepare the raw product dataset for further analysis by identifying and correcting data-quality problems.


PROJECT METHODOLGY:

The workflow followed these major stages:
1.	Inspecting the raw dataset
2.	Identifying missing values
3.	Handling missing categories
4.	Identifying inconsistent text formats
5.	Correcting category errors
6.	Removing duplicate records
7.	Splitting the Product ID into meaningful fields
8.	Merging Product Name and Brand Name
9.	Applying appropriate number and date formats
10.	Applying conditional formatting
11.	Validating the final cleaned dataset


DATASET DESCRIPTION:

                Dataset contains the details about STORE,PRODUCT, BRAND,CUSTOMER,SALES , and DISCOUNT.
It contains city state country wise details and also loyalty type customers helps to find performance.
